# ANN Iris Classification

A clean and simple implementation of an **Artificial Neural Network (ANN)** to classify the classic Iris flower dataset into three distinct species (*Iris setosa*, *Iris virginica*, and *Iris versicolor*) based on sepal and petal measurements.

---

## 🚀 Features
* **Data Preprocessing:** Standard scaling of physical measurements and one-hot encoding for the categorical target labels.
* **Deep Learning Architecture:** Multi-layer feedforward neural network tailored for multiclass classification.
* **Evaluation Metrics:** Tracks accuracy and loss curves across training epochs, concluding with a comprehensive evaluation (confusion matrix/classification report).

---

## 📊 Dataset Overview
The Iris dataset consists of 150 samples with 4 numerical features:
1. Sepal Length (cm)
2. Sepal Width (cm)
3. Petal Length (cm)
4. Petal Width (cm)

**Target Classes:** `Iris-setosa`, `Iris-versicolor`, and `Iris-virginica`.
